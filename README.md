# Service Desk Platform — Система управления тикетами

## 📋 Описание проекта

**Service Desk Platform** — это полноценное desktop-приложение для управления заявками (тикетами) в службе технической поддержки, разработанное на **WPF (.NET 8.0)**. Система предназначена для автоматизации процессов обработки обращений клиентов, контроля сроков выполнения задач, анализа эффективности сотрудников и ведения базы знаний.

Проект реализует современный подход к построению корпоративных информационных систем с использованием:
- Архитектурного паттерна MVVM
- ORM Entity Framework Core
- Базы данных PostgreSQL
- Машинного обучения для классификации тикетов
- Системы логирования Serilog
- Асинхронного программирования

---

## 🚀 Ключевые возможности

### Управление тикетами
- Создание, редактирование и закрытие заявок
- Назначение исполнителей и перераспределение нагрузки
- Отслеживание истории изменений тикета
- Прикрепление файлов к заявкам
- Комментарии и обратная связь
- Контроль сроков выполнения (SLA)

### Ролевая модель
- **Клиенты** — создание заявок, просмотр статуса, оценка качества
- **Сотрудники поддержки** — обработка тикетов, ведение базы знаний
- **Администраторы** — управление пользователями, настройка системы, аудит

### База знаний
- Каталог статей с решениями типовых проблем
- Поиск и рекомендации статей при создании тикета
- Редактирование и версионирование материалов

### Аналитика и отчётность
- KPI сотрудников и подразделения
- Графики и диаграммы (LiveCharts)
- Экспорт отчётов в Excel (ClosedXML)
- Прогнозирование нагрузки

### Уведомления
- Оповещения о новых тикетах
- Напоминания о приближении дедлайнов
- Настройка каналов уведомлений

### Безопасность
- Хеширование паролей (BCrypt)
- Аудит действий пользователей
- Принудительная смена пароля
- Валидация сложности пароля

### Машинное обучение
- Автоматическая классификация тикетов по категориям
- Модель на основе Microsoft ML
- Мониторинг метрик качества модели

### Дополнительные функции
- Глобальный поиск по системе
- Резервное копирование данных
- Тёмная/светлая тема интерфейса
- Персонализация UI (настройки пользователя)

## 🚀 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <url-репозитория>
cd <путь-к-проекту>
```

### 2. Настройка базы данных

1. Установите PostgreSQL (если не установлен)
2. Создайте базу данных:
   ```sql
   CREATE DATABASE servicedesk;
   ```
3. Настройте строку подключения в `appsettings.json` или `Constants.Database.GetConnectionString()`

### 3. Применение миграций

```bash
dotnet ef database update
```

### 4. Сборка проекта

```bash
dotnet restore
dotnet build
```

### 5. Запуск приложения

```bash
dotnet run
```

Или откройте решение в Visual Studio 2022 и нажмите F5.

## 🔐 Безопасность

### Хеширование паролей
Все пароли хранятся в хешированном виде с использованием алгоритма **BCrypt**.

### Аудит
Система ведёт журнал всех значимых действий пользователей:
- Вход/выход из системы
- Создание/изменение/удаление тикетов
- Изменение настроек
- Экспорт данных

### Валидация паролей
Требования к паролю:
- Минимум 8 символов
- Заглавные и строчные буквы
- Цифры и специальные символы

## 🤖 Машинное обучение

Проект включает ML-модель для автоматической классификации тикетов:

- **Алгоритм**: FastTree (градиентный бустинг)
- **Признаки**: Текст заголовка, описание, категория клиента
- **Цель**: Предсказание категории и приоритета тикета
- **Обучение**: Выполняется на исторических данных
- **Метрики**: Точность, полнота, F1-мера сохраняются в БД

Модели хранятся в папке `MLModels/` в формате `.zip`.

## 📈 Аналитика и отчёты

Система предоставляет следующие виды отчётов:

1. **Оперативные метрики**
   - Количество открытых/закрытых тикетов
   - Среднее время решения
   - Процент соблюдения SLA

2. **KPI сотрудников**
   - Количество обработанных заявок
   - Средняя оценка клиентов
   - Время реакции

3. **Прогнозирование**
   - Оценка будущей нагрузки
   - Выявление пиковых периодов

4. **Экспорт**
   - Excel (XLSX) через ClosedXML
   - PDF через PDFsharp/Eshava.Report
