# Service Desk Platform — автоматическая демонстрация (4:30)

Скринкаст управляется автоматически: окно WPF-приложения собирается в Release,
запускается, а отдельный консольный драйвер на **FlaUI (UIA3)** находит элементы по
`AutomationId` (= `x:Name`) и кликает/вводит текст с видимым движением курсора и
паузами. Экран пишется через **ffmpeg gdigrab** (30 fps, без звука), затем итог
обрезается до ровно **270.0 c**.

## Как воспроизвести

```powershell
# 1. Сборка приложения
dotnet build "КР Ханников.csproj" -c Release

# 2. БД засеяна DbSeeder (admin/support/client), admin.MustChangePassword = false

# 3. Сборка драйвера
dotnet build C:\demo_build\DemoDriver -c Release

# 4. Запись + прогон + обрезка (см. demo/record_demo.ps1)
powershell -File demo/record_demo.ps1
```

## Технические заметки

- Драйвер делает процесс DPI-aware (`PerMonitorV2`), поэтому координаты UIA и курсора
  совпадают (физические пиксели 1920×1080 при 125 % масштабе ОС).
- Движение курсора — плавная интерполяция (ease-in-out), без телепортации.
- Найден и исправлен баг холодного старта: `DbSeeder.SeedAsync(ctx).Wait()` на UI-потоке
  давал async-over-sync deadlock на пустой БД — обёрнуто в `Task.Run(...).GetAwaiter().GetResult()`.
- Итог: `demo/demo.mp4`, 1920×1080, ровно 270.0 c.
